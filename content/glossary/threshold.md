---
term: Threshold
definition: A threshold is a cut-off number you pick to help your code make a decision. The code checks whether a value is above or below it, then acts. It's like drawing a line and asking "are we over it or under it?"
category: Logic
example: 'Like setting a bedtime of 8 o''clock: before 8 you''re still up, after 8 it''s lights out. The time is your threshold.'
