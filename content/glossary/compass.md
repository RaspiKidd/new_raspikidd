---
term: Compass
definition: A compass senses which way you are facing and turns it into a number your code can read, from 0 all the way round to 359. North is 0, east is 90, south is 180 and west is 270.
category: Hardware
example: Like the little arrow on a map app that swings round as you turn, a compass tells your code which way you are pointing.
